Impulsa — Plataforma de Voluntariado
Plataforma full-stack que conecta voluntarios con organizaciones, pensada para reducir la brecha entre personas que quieren ayudar y organizaciones que necesitan apoyo. Los voluntarios se registran, exploran actividades y reciben recomendaciones según sus intereses; las organizaciones publican y gestionan sus propias oportunidades y postulantes.

Funcionalidades clave: autenticación con JWT diferenciada por rol, sistema de recomendaciones personalizado, chatbot de asistencia integrado con la API de OpenAI, generación automática de diplomas en PDF, pagos y donaciones vía Mercado Pago, y notificaciones por correo.

Mi rol: desarrollo full-stack — diseño de la base de datos en PostgreSQL, API REST en Node.js/Express, y la interfaz en React.

Nombre del Proyecto
Sistema full-stack para administrar productos, categorías y stock, con foco en integridad transaccional de los datos. La decisión de diseño central: el stock nunca se escribe directo, siempre se deriva de un historial de movimientos (entradas/salidas) — ni al crear un producto ni al editarlo.

Detalles técnicos que vale la pena resaltar: cada movimiento corre dentro de una transacción SQL con bloqueo de fila (SELECT ... FOR UPDATE) para evitar condiciones de carrera entre movimientos simultáneos sobre el mismo producto, y validación en dos capas para que el stock nunca quede negativo (a nivel de aplicación y con un CHECK constraint en la base de datos). Incluye además un panel de control con KPIs y gráficos de entradas/salidas construidos con queries agregadas.

Mi rol: desarrollo full-stack — modelado de la base de datos, API REST en Node.js/Express, y panel de control en React.
